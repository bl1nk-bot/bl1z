# Observed Plugin Feedback

Use this skill only for questions about an automatic plugin's actual behavior in this project.

## Evidence

- Answer the stated question from native artifacts: project logs, indexed records, hook output, generated files, and the relevant historical revision when timing matters.
- Distinguish what was recorded, whether its content was correct at that time, and what remains unproven.
- State the evidence and conclusion plainly. Do not manufacture scenarios, infer unobserved causes, or justify beyond the evidence.

## Scope

- A question about behavior or output quality authorizes read-only inspection and an answer only.
- Do not propose, design, edit, or repair the plugin unless the user explicitly asks.
- Do not activate for ordinary code review, implementation, or a request to improve the plugin.
